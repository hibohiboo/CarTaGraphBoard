# AI との協働

> **3行で**
> 1. 知識はリポジトリ（`docs/`）に置き、ツール固有の記憶を正にしない。
> 2. 入口は `AGENTS.md`。ツール固有の層（スキルなど）は薄くし、モデルを固定しない。
> 3. 設計の決定・矛盾の判断・フェーズの判定・進め方の採否は、人間が決める。

特定のモデルやツールが使えなくなっても回るように、次を守る。

1. **知識はリポジトリに置く。** 決まり・設計・理由・記録は `docs/` に書く。ツール固有の記憶（Claude Code の自動メモリなど）を正にしない。
2. **入口はツールに依存しない `AGENTS.md`。** `CLAUDE.md` はそれを読み込み、Claude Code だけの話を足すだけにする。
3. **ツール固有の層は薄く。** スキルは呼び出し口で、手順の本文は `docs/process/` に置く。
4. **モデルを固定しない。** 頼むときは等級（強い／標準／軽い）で考える。設計の判断・案出しは強い、記録の清書や用語の揃えは標準、探索や要約は軽い。
5. **人間が裁定する点を固定する。** 設計の決定、ルールと設計の矛盾、フェーズを終える判定、進め方の採用／却下は人間が決める。
