# コンポーネント

> **3行で**
> 1. 遊ぶのに要るものを全部、数とともに挙げる。ここに無いものは、ルールで使わない。
> 2. 使えるのはカード・シート・コマ・ダイス（[DR-0005](../decisions/DR-0005-紙とオンラインツールの両方で遊ぶ.md)）。
> 3. いまはカードの種類（キャラクターのデッキ・シーンのカード・配るカード・白紙のカード・プロキシ）と卓の箱、最初の1回のキャラクターのデッキとプロキシの数が決まった。シナリオの束と白紙のカードの数、判定・戦闘・成長に使うものは後のサイクルで足す。

> 状態：フェーズ2で埋めている。最初に紙で通す1回（[DR-0012](../decisions/DR-0012-最初に紙で通す範囲.md)）の分から。

## 一覧

| コンポーネント | 数 | 何に使うか | 使うルールの節 |
|---|---|---|---|
| キャラクターのデッキ | 最初の1回は出来合いを1つ（8枚） | キャラクターを表す。5枚をアクティブのカードにする | [準備](rules.md#準備)、[ビート](rules.md#ビート)、[遊んだ後](rules.md#遊んだ後) |
| シナリオの束 | 最初の1回は1つ。枚数は未定 | シーンのカードと配るカードのひとそろい | [ゲームの流れ](rules.md#ゲームの流れ) |
| 白紙のカード | 未定 | 手札に無い一手を書く | [ビート](rules.md#ビート)、[遊んだ後](rules.md#遊んだ後) |
| プロキシ | シーンのカード・配るカード1枚につき1枚、キャラクターのデッキのカード1枚につき3枚。ほかに白紙のプロキシ（数は未定） | 出したカードとシーンを足跡の列に並べる | [ビート](rules.md#ビート)、[遊んだ後](rules.md#遊んだ後) |
| 卓の箱 | 卓に1つ | 足跡の列と、残した白紙のカードをしまう | [遊んだ後](rules.md#遊んだ後) |

## キャラクターのデッキ

- 中身：キャラクターを表すカードの集まり。切って引く山札にはしない（[DR-0015](../decisions/DR-0015-キャラクターのデッキとアクティブ.md)）。セッションから持ち帰ったカードと、成長で取ったカードも入る（後のサイクル）。
- 最初の1回：出来合いのキャラクターのデッキ8枚（特徴2・技能3・装備3。種類分けは（仮））。
- 見た目：表に名前・イラスト・タグ・効き目。裏は共通。大きさと効き目の書き方は後のサイクル。
- 誰が持つか：PL。次の回に持ち越す。
- 遊んでいる間：5枚をアクティブのカードとして表向きに並べる。出したら横に倒す。

## シナリオの束

- シーンのカード：番号の付いたカード。表に番号・描写・選択肢（「【タグ】→ 番号」）を書く。「配る」「休む」の指示や、判定・戦闘の指示を書くこともある。結末のシーンのカードには「結末」と報酬を書く。
- 配るカード：タグ付きのカード。返すとき（ビートの終わり・シーンの終わり・シナリオの終わり）を書く。選択肢のカード（「頷く」「断る」など、ビートの終わりに返す）と、シナリオの間持つカード（「通行証」など）がある。
- 誰が持つか：GM が番号順に持ち、PL には見せない。
- 遊んだ後：変わらない。配るカードはすべて束に戻す。
- 作るときの決まり：どのシーンも、それまでに配ったカードだけで、少なくとも1つの選択肢を選べるようにする（[DR-0013](../decisions/DR-0013-シーンと手札のつながり.md)）。

## タグを付ける目安

どのカードも、作るときの目安は、ふつう1〜2個。スキルやアイテムには、もっと付けてよい。選択肢のカードは、カードの名前を1個のタグにする（例：「頷く」に【頷く】）。ルールでは数を縛らない（[DR-0016](../decisions/DR-0016-配るカードの行き先とプロキシの枚数.md)）。

## 白紙のカード

- 見た目：何も書いていないカード。設計者が作ったカードと見た目で区別する。
- 遊んだ後：卓に残すと決めたものは、卓の箱にしまう。

## プロキシ

- 見た目：名前とイラストだけを載せた小さなカード。キャラクターのデッキのカード・配るカード・シーンのカードごとに用意する（[DR-0014](../decisions/DR-0014-足跡とプロキシ.md)）。
- 数：最初の1回は、シーンのカード・配るカード1枚につき1枚、キャラクターのデッキのカード1枚につき3枚（[DR-0016](../decisions/DR-0016-配るカードの行き先とプロキシの枚数.md)）。オンラインセッションツールでは画像を複製する。
- 白紙のプロキシ：名前を書き込めるプロキシ。足りなくなったときに使う。
- 遊んだ後：足跡の列として、卓の箱にしまう。

## 卓の箱

- 卓ごとに1つ。遊ぶためのものではなく、卓に残るもの（足跡の列・残した白紙のカード）をしまう入れ物。
