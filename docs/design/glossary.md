# 用語集

> **3行で**
> 1. ゲームの言葉の意味は、ここだけで決める（DDD の「ユビキタス言語」）。
> 2. 設計・ルール・モデル・会話で、同じものは同じ言葉で呼ぶ。
> 3. 言葉は五十音順。新しい言葉が要るときは、使う前にここに足す。

## 書き方

言葉ごとに見出しを立て、次を書く。五十音順に並べる。

```markdown
### <言葉>

<1〜2文の意味>

- 例：…（あれば）
- 別の呼び方：…（使わない言い方。言い換えたときは旧い言葉をここに残す）
```

## 言葉

### キャラクターのデッキ

遊ぶ人が自分のキャラクターとして持つカードの束。キャラクターが成長して得たカードが加わり、次の回に持ち越す。

### シナリオ

1回の冒険の筋書きと、それに使うカードの束。遊ぶ人はいくつかのシナリオから選んで遊ぶ。設計者が後から追加のシナリオを足せる。

### 設計者

カルタグラフのルールと、正式なカード・シナリオを作る人。遊ぶ人とは別の役割（兼ねてもよい）。

### 卓

一緒に遊ぶ人の集まりと、その人たちが続けて使うカード・シート・箱のひとそろい。育ったものは卓ごとに違う。

- 例：「この卓の白紙のカード」

### 白紙のカード

遊んでいる途中に、遊ぶ人が手札に無い一手を思いついたときに書き込むカード。卓に残せる。設計者が作ったカードと見た目で区別する。
