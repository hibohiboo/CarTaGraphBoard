# ルール

> **3行で**
> 1. 準備から終わりまで、遊ぶ人がこのページだけを読んで進められるように書く。
> 2. 言葉は [用語集](glossary.md) のもの、使うものは [コンポーネント](components.md) にあるものだけ。各節の頭に「する人」「使うもの」を書く。
> 3. シナリオはシーンのカードを番号で辿って進む。PL は手札（シーンが配るカードと、キャラクターのデッキから選んだアクティブのカード5枚）から1枚出してシーンの選択肢を選び（1ビート）、出したカードのプロキシを足跡の列に並べていく。判定は「2d6＋カードの修正 ≥ 目標値」、戦闘はスクエアの盤面とカウント制で、PC と仲間が敵と戦う。

> 状態：フェーズ2で埋めている。いまは最初に紙で通す1回の骨組み（[DR-0012](../decisions/DR-0012-最初に紙で通す範囲.md)）。成長と報酬は後のサイクルで書く。数字は（仮）で、試遊で直す。

各節の頭に、次の2行を書く（RDRA の「関係でつなぐ」。フェーズ4でモデルに写すときの手がかりになる）。

- **する人** — 遊ぶ人・GM など
- **使うもの** — コンポーネント

ゲームの流れは、起きること（イベント）を「〜した」の形で並べてから、文にする。

## ゲームの目的

- **する人** — GM・PL
- **使うもの** — シナリオの束

PL は、キャラクターを動かしてシナリオを進め、結末を迎える。GM と PL は対戦しない（[やらないこと](vision.md#やらないこと)）。どの結末に行き着いたかと、その途中で出したカードが、足跡として卓に残る。

## 準備

- **する人** — GM・PL
- **使うもの** — キャラクターのデッキ、パーティの束、シート、シナリオの束、白紙のカード、プロキシ、盤面、カウントボード、コマ、ダイス、卓の箱

1. PL は、キャラクターのデッキから5枚を選び、アクティブのカードとして表向きに並べる。残りのカードは脇に置く。最初の1回は、出来合いのキャラクターのデッキ（8枚）を使う（[最初の1回のひとそろい](starter.md)）。
   - PL は、シートの HP の欄の、特徴のカードに書いた HP の目盛りにコマを置く。
   - PL は、パーティの束から、連れていく仲間のカードを選ぶ（数は（仮）で2体まで）。
2. GM は、遊ぶシナリオの束を手元に置く。束のシーンのカードは番号順に並べ、PL には見せない。
3. 白紙のカード、デッキ・束のカードのプロキシ、白紙のプロキシを、手の届くところに置く。
4. 卓に、足跡の列を置く場所を空ける。盤面・カウントボード・コマ・ダイスは、戦闘のシーンが来たら出す。

## ゲームの流れ

```text
準備した → シーンを開いた → ビートを回した → 次のシーンを開いた … → 結末のシーンを開いた → 報酬を受け取った → 足跡をしまった
```

1. GM は、束の1番のシーンのカードを開いて読み、描写する。
2. シーンのカードの指示に従い、ビートを回す（[ビート](#ビート)）。選択肢に判定があれば、振って行き先を決める（[判定](#判定)）。戦闘のシーンは、手番で区切る（[戦闘](#戦闘)）。
3. 選んだ選択肢の番号のシーンのカードを、GM が開く。2に戻る。
4. 「結末」と書いたシーンのカードを開いたら、[終わりと結末](#終わりと結末)へ進む。

## ビート

- **する人** — PL（カードを出す）・GM（読む、白紙のカードを認める）
- **使うもの** — シーンのカード、手札（アクティブのカード・配るカード）、白紙のカード、プロキシ

カードを1枚出すまでを、1ビートとする。ふだんは1シーンで1ビート。

1. GM は、シーンのカードに「休む」とあれば、そう告げる。PL は、倒れたカードをすべて起こし、PC と仲間の HP を特徴のカード・仲間のカードの値まで戻す（HP を戻すのは（仮））。
2. GM は、シーンのカードに「配る」とあれば、そのカードを束から PL の手札に加える。
3. PL は、シーンのカードの選択肢（例：「【交渉】→ 3」）から1つを選び、そのタグを持つカードを手札から1枚出す。倒れたカードは出せない。選択肢に判定があれば、[判定](#判定)をする。タグの無い選択肢（例：「→ 5」）は、カードを出さずに選べる。そのときは6で、下の段に何も置かない（[DR-0022](../decisions/DR-0022-タグの無い選択肢.md)）。
4. 手札に無い一手を思いついたら、PL は代わりに白紙のカードに1文を書いて出してよい。GM が認めたら、GM はそのシーンのカードにある行き先から1つを選ぶ。認めなければ、PL は3に戻る。
5. 出したカードは、次のようにする。
   - 配るカード：すぐ束へ返す。
   - アクティブのカード：横に倒す。
   - 白紙のカード：実物を足跡の列の下の段に置く。
6. 足跡の列の上の段にシーンのプロキシを、下の段に出したカードのプロキシを置く。プロキシが足りなければ、白紙のプロキシに名前を書いて置く。
7. 出さなかった配るカードは、カードに書いた「返すとき」（ビートの終わり・シーンの終わり・シナリオの終わり）に束へ返す。

ビートとビートの間なら、PL はいつでも、アクティブのカードとデッキのほかのカードを入れ替えてよい。倒れたカードは外せない。

## 判定

- **する人** — PL（振る）・GM（目標値を読む）
- **使うもの** — シーンのカード、手札、ダイス（6面2個）

シーンのカードの選択肢に、判定が付いていることがある（例：「【剣】判定9 → 成功 4／失敗 5」）。

1. PL は、選択肢のタグを持つカードを手札から1枚出す（[ビート](#ビート)の3）。
2. PL は、2d6 を振り、出したカードに書いた修正を足す。判定の数（目標値）以上なら成功、足りなければ失敗。
3. 「振らない」と書いたカード（支援・回復など）は、振らずに成功する。ただし、シーンのカードに「振る」とあれば振る。
4. GM は、成功か失敗の番号のシーンのカードを開く。

## 戦闘

- **する人** — PL（PC と仲間を動かす、攻撃を振る）・GM（敵を動かす、伏せたカードを使うか聞く）
- **使うもの** — 戦闘のシーンのカード、敵のカード、仲間のカード、手札、盤面、カウントボード、コマ、シート、ダイス

戦闘のシーンのカードには、敵、コマを置く位置、勝ちの条件（例：「敵を全部倒す」「3ラウンド持ちこたえる」）、行き先（「勝ち → 番号」「負け → 番号」「逃げた → 番号」）を書く。

```text
戦闘のシーンを開いた → コマを置いた → ラウンドを始めた → 手番を回した … → ラウンドを終えた … → 勝敗がはっきりした → 足跡を置いた
```

### 始める

1. GM は、盤面に、戦闘のシーンのカードのとおりに PC・仲間・敵のコマを置く。1マスに置けるコマは1つ。
2. GM は、敵のカードを並べ、敵ごとに HP の目盛りにコマを置く。PL は、仲間のカードについて同じようにする。
3. 戦う者ごとに、カウントボードの0の目盛りにコマを置く。

### ラウンド

1. 戦う者（PC・仲間・敵）ごとに、カウントボードのコマを、今の目盛りから速さの分だけ上げる。前のラウンドで0より下になった者は、その分だけ少なくなる（持ち越し）。PC の速さは特徴のカードに、仲間と敵の速さはそのカードに書いてある。
2. カウントのいちばん大きい者が、手番を取る（[手番](#手番)）。同じなら PC 側が先で、PC と仲間の順は PL が、敵どうしの順は GM が決める。
3. 2をくり返す。カウントが0以下になった者は、このラウンドでは手番を取らない。カウントが1以上の者は、手番を飛ばさない。
4. 全員が0以下になったら、ラウンドが終わる。「ラウンド1回」と書いた倒れたカードを起こす。1に戻る。

### 手番

1. 手番を取った者は、行動を1つして、そのカウントを払う。カウントボードのコマを、払った分だけ下げる。カウントが1以上なら、残りより多いカウントの行動もしてよい。コマは0より下の目盛りまで下げ、足りない分は次のラウンドに持ち越す（[DR-0021](../decisions/DR-0021-カウントの持ち越し.md)）。
2. 行動は次のどれか。数字は（仮）。
   - **カードを出す** — アクティブのカードを出し、カードに書いたカウントを払う。戦闘の中では倒さない。「1戦闘1回」「ラウンド1回」と書いたカードだけ倒す。
   - **動く** — 1カウントで2マスまで動く。斜めに1つ進むのは2マスと数える。乱戦から抜けるときは、さらに2カウント払う。
   - **伏せる** — 「割り込み」と書いたアクティブのカードを1枚、裏向きに伏せる。1カウント。どれを伏せるかは PL が選ぶ。GM には枚数だけが見える。
   - **逃げる** — 4カウント払い、「逃げた」の行き先へ進む。白旗を上げるときも同じ。
   - **白紙のカードを出す** — 手札に無い一手を書いて出す。GM が認めたら、効き目とカウントを GM が決める（目安：4カウントで、ダメージ4か、敵の手番を1回飛ばす）（仮）。
3. 敵と仲間は、カードの行動を上から見て、当てはまる最初の1つをする。敵は GM が、仲間は PL が動かす。

### 攻撃と HP

1. 敵のコマと、PC か仲間のコマが隣り合ったら（縦・横・斜め）、乱戦になる。同じコマを通してつながった乱戦は、1つの乱戦とする。味方どうしが隣り合うだけでは、乱戦にならない（[DR-0023](../decisions/DR-0023-乱戦は敵と味方の間だけ.md)）。カードに射程が無ければ、攻撃できるのは同じ乱戦の相手だけ。射程は、動くときと同じく、斜めに1つを2マスと数える。
2. PC の攻撃：PL は「2d6＋カードの命中の修正」を振る。敵の回避以上なら当たる。
3. 敵と仲間の攻撃：振らずに当たる。
4. 当たったら、カードに書いたダメージだけ、相手の HP のコマを下げる。カードに「＋1d6」などとあれば、振って足す。受けるダメージを減らすのは、カードの効果で行う。
5. HP が0になった者は倒れ、盤面からコマを除く。死にはしない。

### 割り込み

1. 伏せたカードがあるときだけ、GM は、カードの条件（例：「攻撃を受けたとき」）が来たら「使いますか」と聞く。
2. PL が使うと言ったら、カードを表にして効き目を使い、倒す。カウントは払わない（仮）。

### 終わる

1. 勝ちの条件を満たしたら、その場で戦闘が終わる。PC が倒れたら負けで、その場で終わる。逃げたら、その手番で終わる。
2. 戦闘の中で倒したカードを起こす（仮）。伏せたカードを表に戻す。HP はそのまま次のシーンへ持ち越す。
3. 足跡の列の上の段に戦闘のシーンのプロキシを、下の段に PL が選んだ「決め手」のカードのプロキシを1枚置く。白紙のカードを出していたら、実物も置く。
4. GM は、勝ち・負け・逃げたのうち、当てはまる番号のシーンのカードを開く。

## 終わりと結末

- **する人** — GM・PL
- **使うもの** — 結末のシーンのカード、プロキシ

1. GM は、結末のシーンのカードを読み、描写する。そのプロキシを足跡の列の最後に置く。
2. 手札に残った配るカードを、すべて束に返す。
3. PL は、結末のシーンのカードに書いた報酬を受け取る。持ち帰るカード（配っていた仲間のカードも含む）は、GM が束から配り直す。PL は、持ち帰るカードをキャラクターのデッキ（仲間のカードはパーティの束）に入れる。成長は後のサイクルで書く。

## 遊んだ後

次の回に何が残るか（[進化の表し方](vision.md#進化の表し方)）。

- **する人** — GM・PL
- **使うもの** — 足跡の列、白紙のカード、キャラクターのデッキ、卓の箱

1. 足跡の列を、並べたまま卓の箱にしまう。
2. 白紙のカードを卓に残すかを決める（決め方は後のサイクルで書く）。
3. PL は、倒れたカードを起こし、アクティブのカードをキャラクターのデッキに戻す。仲間のカードをパーティの束に戻す。成長は後のサイクルで書く。
