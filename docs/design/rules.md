ゲームの流れは、起きること（イベント）を「〜した」の形で並べてから、文にする。

## ゲームの目的

- **する人** — GM・PL
- **使うもの** — シナリオの束

PL は、キャラクターを動かしてシナリオを進め、結末を迎える。GM と PL は対戦しない（[やらないこと](vision.md#やらないこと)）。どの結末に行き着いたかと、その途中で出したカードが、足跡として卓に残る。

## 準備

- **する人** — GM・PL
- **使うもの** — キャラクターのデッキ、シナリオの束、白紙のカード、プロキシ、卓の箱

1. PL は、キャラクターのデッキを切って山札にし、手札を5枚引く（仮）。最初の1回は、出来合いのキャラクターのデッキを使う。
2. GM は、遊ぶシナリオの束を手元に置く。束のシーンのカードは番号順に並べ、PL には見せない。
3. 白紙のカードと、デッキ・束のカードのプロキシを、手の届くところに置く。
4. 卓に、足跡の列を置く場所を空ける。

## ゲームの流れ

```text
準備した → シーンを開いた → ビートを回した → 次のシーンを開いた … → 結末のシーンを開いた → 報酬を受け取った → 足跡をしまった
```

1. GM は、束の1番のシーンのカードを開いて読み、描写する。
2. シーンのカードの指示に従い、ビートを回す（[ビート](#ビート)）。判定と戦闘のシーンは、手番で区切る（後のサイクルで書く）。
3. 選んだ選択肢の番号のシーンのカードを、GM が開く。2に戻る。
4. 「結末」と書いたシーンのカードを開いたら、[終わりと結末](#終わりと結末)へ進む。

## ビート

- **する人** — PL（カードを出す）・GM（読む、白紙のカードを認める）
- **使うもの** — シーンのカード、手札、配るカード、白紙のカード、プロキシ

カードを1枚出すまでを、1ビートとする。ふだんは1シーンで1ビート。

1. GM は、シーンのカードに「配る」とあれば、そのカードを束から PL の手札に加える。
2. PL は、シーンのカードの選択肢（例：「【交渉】→ 3」）から1つを選び、そのタグを持つカードを手札から1枚出す。
3. 手札に無い一手を思いついたら、PL は代わりに白紙のカードに1文を書いて出してよい。GM が認めたら、GM はそのシーンのカードにある行き先から1つを選ぶ。認めなければ、PL は2に戻る。
4. 出したカードの実物は捨て札に置き、そのプロキシを足跡の列に置く。列は、上の段にシーンのプロキシ、下の段に出したカードのプロキシ。白紙のカードは実物を下の段に置く。
5. PL は、山札から1枚引く（仮）。山札が尽きたら、捨て札を切って山札にする（仮）。
6. 配るカードに書いた「返すとき」（ビートの終わり・シーンの終わり・シナリオの終わり）が来たら、そのカードを、手札・山札・捨て札のどこにあっても束へ返す（仮）。

## 終わりと結末

- **する人** — GM・PL
- **使うもの** — 結末のシーンのカード、プロキシ

1. GM は、結末のシーンのカードを読み、描写する。そのプロキシを足跡の列の最後に置く。
2. PL は、結末のシーンのカードに書いた報酬を受け取る。持ち帰るカードは、配るカードを一度束に返した後に、報酬として配り直す（報酬の中身は後のサイクルで書く）。
3. 配るカードを、すべて束に返す。

## 遊んだ後

次の回に何が残るか（[進化の表し方](vision.md#進化の表し方)）。

- **する人** — GM・PL
- **使うもの** — 足跡の列、白紙のカード、キャラクターのデッキ、卓の箱

1. 足跡の列を、並べたまま卓の箱にしまう。
2. 白紙のカードを卓に残すかを決める（決め方は後のサイクルで書く）。
3. PL は、手札・山札・捨て札をキャラクターのデッキに戻す。成長は後のサイクルで書く。
