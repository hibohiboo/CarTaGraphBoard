# 問い

> **3行で**
> 1. まだ決めていない問いを、1問1行で置く。
> 2. [設計サイクル](process/cycle.md)の初めに、ここから今回決める問いを束ねる。
> 3. 決めたら行を消し、決定（`docs/decisions/`）のほうに問いを書く。

書式：`- <問い> — <なぜ要るか・関わる終える条件>（<日付>）`

## いまのフェーズ（1. コンセプト）

- 前のリポジトリのどの要素（進化ループ・カードとデッキ・判定・戦闘・成長・グラフ・解放・提案・ビート…）を採るか。体験の核（DR-0003）と3つの層（DR-0004）に照らして仕分ける — 前のリポジトリの仕分け（2026-11-01）
- コアとそうでないところ。前のリポジトリの仕分けと一緒に決める — 前のリポジトリの仕分け（2026-11-01）
- キャラクターメイクの自前のツールを、フェーズ5で作る（それまでは紙のシート）でよいか。いまは（仮）。DR-0001 と食い違わない読み方で置いた — デザインの柱（2026-11-01）
