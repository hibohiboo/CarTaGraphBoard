# DR-0021 カウントの持ち越しと、斜めの数え方

- 状態：採用（数字は（仮））
- 日付：2026-11-24
- サイクル：[C9](../cycles/2026-11-03-C9-最初の1回の中身.md)
- 反映先：[ルール](../design/rules.md#ラウンド)、[コンポーネント](../design/components.md)（カウントボード）、[用語集](../design/glossary.md)

## 問い

- [DR-0018](DR-0018-戦闘の形.md) の（仮）「カウントが0より大きければ、残りより多いカウントの行動もしてよい」では、速さ6でも8でも4カウントの行動を1ラウンドに2回でき、速さの差が効かない。どうするか。
- 動くマスと射程で、斜めをどう数えるか。

## 決めたこと

- カウントが1以上なら、残りより多いカウントの行動もしてよい。払いきれない分は、カウントボードの0より下の目盛りまでコマを下げ、次のラウンドに持ち越す。0以下なら行動できない。
- ラウンドの初めには、コマを今の目盛りから速さの分だけ上げる（「速さの目盛りに置く」を置き換える）。
- カウントボードの目盛りは −3〜12（仮）。4カウントの行動を1で始めると −3 になる。
- 動くマスと射程は、斜めに1つを2マスと数える。乱戦は、これまでどおり斜めも隣り合いとする。

## 理由

- 人間の答え：持ち越しの形（プロバビリティスカイ）。ただし0以下では行動できず、1でもあれば持ち越して行動してよい。斜めは2マス。
- 速さの差が、平均の手番の数に比例して出る。速さ6で4カウントの攻撃は、ラウンドごとに2回・1回・2回…（平均1.5回）、速さ8なら毎回2回。速さが数字で育つ意味を持つ（柱3）。
- 持ち越しはコマの位置そのものに残るので、覚えておく数が増えない。ラウンドの初めの操作も「速さの分だけ上げる」の足し算1回で済む（柱2）。
- 頭の中で通した：最初の1回の戦闘は、全部当たると2ラウンドで勝ち、リオの HP は 18 → 8（サイクルの記録の「確かめたこと」）。

## 採らなかった案

- **今の（仮）のまま** — 速さの差が効かない。
- **残りより多い行動はできない（AI の推奨）** — 速さの差は出るが、2〜3の余りが出て、端数のカウントが重い行動に使えない。
- **0以下でも持ち越して行動してよい** — 借りが際限なく積もる。

## 後で見直すとき

試遊で、借りの多い者の手番が来ないまま戦闘が終わるとき。白紙のカードで大きなカウントを払い、−3 を下回るとき。
