# DR-0015 キャラクターのデッキとアクティブ

- 状態：採用（戦闘の中で倒すカードと起こすときは DR-0018 で決めた）
- 日付：2026-11-02
- サイクル：[C7](../cycles/2026-11-02-C7-キャラクターのデッキ.md)
- 反映先：[ルール](../design/rules.md)「準備」「ビート」「遊んだ後」、[コンポーネント](../design/components.md#キャラクターのデッキ)、[用語集](../design/glossary.md)

## 問い

- キャラクターのデッキは、何枚で、どう作るか。
- 手札は何枚で、出した後にどう補うか（C6 の仮：手札5枚、出したら1枚引く、山札が尽きたら捨て札を切る）。

## 決めたこと

- キャラクターのデッキは、キャラクターを表すカードの集まりにする。切って引く山札にはしない。戦闘や特徴など、キャラクターを表すカードのほか、セッションから持ち帰ったカード（クリア証・経験点・アイテム・スキルなど）と、成長で取ったカードが入る。
- PL は、デッキから5枚を選んで、アクティブのカードとして表向きに並べる。手札は、アクティブのカードと、シーンから配られたカードを合わせたもの。山札・捨て札は無い。
- アクティブのカードを出したら、横に倒す。倒れたカードは出せない。シーンのカードに「休む」とあるとき（野営・宿など）と、シナリオの終わりに起こす。
- ビートとビートの間なら、PL はいつでも、アクティブのカードとデッキのほかのカードを入れ替えてよい。倒れたカードは外せない。
- 最初の1回の出来合いのキャラクターは、デッキ8枚（特徴2・技能3・装備3）、うちアクティブ5枚。種類分けは（仮）。
- 手札に置く重みは「選択肢のカード（シーンが配る「頷く」「断る」など）＞ シナリオの間持つ配るカード・アクティブのカード」。進めるのはシナリオからの提案が主で、キャラクターのデッキのカードは思いついたときに出す。

## 理由

- 人間が描くキャラクターは、ソード・ワールドのような、泥臭い、何者でもない冒険者。デッキはガープスのように、キャラクターを表すカードを集めたものにしたい。
- 人間の好み：ドミニオンのように、デッキが育つ過程も最後の姿も楽しい。TCG のように、何を入れるか悩むのが楽しい。デッキを集まりにし、アクティブを選ぶ形なら、育つことと選ぶことの両方を味わえる（柱3）。
- カードワースのように、1人5枚ほどをアクティブにする情報量は、把握しやすい（人間）。
- 「シナリオからの提案」は配るカードのこと（人間）。どの選択肢もカードを1枚出して選ぶ形（[DR-0013](DR-0013-シーンと手札のつながり.md)）・柱4・コア3 を変えずに済み、毎ビート、足跡にカードが1枚並ぶ。
- 倒す・起こすだけで、計算は要らない（柱2）。起こすのを「休む」ときにしたのは、頭の中で通して、シーンの終わりに起こすと1シーン1ビートでは倒す意味が無いと分かったため。休むまでのやりくりが、泥臭い冒険者らしさと、「ここぞ」でキャラクターのデッキのカードを出す重みになる。休む場所はシナリオで調整できる。
- 倒れたカードを外せないのは、外して入れ替えると倒した分がすぐ戻るため。1文で塞げる。
- 引く手間（C6 の「1枚引く」）が消え、1ビートの手間が減った。

## 採らなかった案

- **山札と、遊ぶ前に選ぶ切札（桜降る世に決闘を）** — 切札はトーキョーN◎VA の神業のような、ドラマチックなゲームに合う。考えている冒険者には合わない。シナリオに出てくるのはよいが、コアではない（人間）。
- **山札から引く形（手札5枚、出したら1枚引く）** — デッキはキャラクターを表す集まりにしたい（人間）。
- **アクティブのカードを何度でも出せる** — 同じタグのカードが1枚あれば、そのタグの選択肢がいつでも開き、配るカードの意味が薄れる。
- **カードごとに使用回数を書く（カードワース）** — 回数を記録する手間が増える。
- **シーンの終わりに起こす** — ふだんは1シーン1ビートなので、倒す意味が無い。
- **倒れたカードも外してよいが、代わりに入れたカードも倒れて入る／組み替えは休むときだけ** — 前者は決まりが長く、後者は「いつでも組み替えてよい」が狭まる。
- **デッキ5枚だけで組み替え無し／12枚前後** — 前者は組み替えを試せない。後者は最初の1回には多い。

## 後で見直すとき

試遊で、休むまでにキャラクターのデッキのカードが尽きて白紙のカードばかりになるとき、逆に倒れることがほとんど無いとき。アクティブ5枚が多すぎる・少なすぎると分かったとき。
