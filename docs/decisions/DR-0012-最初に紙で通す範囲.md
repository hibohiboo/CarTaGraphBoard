# DR-0012 最初に紙で通す範囲

- 状態：採用
- 日付：2026-11-02
- サイクル：[C6](../cycles/2026-11-01-C6-最初に紙で通す範囲.md)
- 反映先：[ルール](../design/rules.md)、[コンポーネント](../design/components.md)、[問い](../questions.md)（後から足すもの）

## 問い

フェーズ2の終える条件「紙で1回通して遊ぶ」のために、最初の1回に何を入れ、何を後から足すか。

## 決めたこと

最初の1回に入れるもの：

- GM 1人・PL 1人で、シナリオ1本（[DR-0006](DR-0006-遊ぶ場面.md)）
- コアの4つ（[DR-0010](DR-0010-コア.md)）
- 判定と、戦闘1回（形は後のサイクルで決める）
- 遊んだ後（成長、白紙のカードを卓に残す）
- シナリオの束は、GM がいなくても読めば進める形で作る。ただし最初の1回は GM がいる形で遊ぶ

後から足すもの：

- キャラクターメイクの手順（最初は出来合いの PC 1人で始める）
- GM がいないときだけ要る決まり（白紙のカードを誰が認めるか、自動の戦闘、村）
- 遊び終えた後に、外から意見や称号をもらう仕組み
- カードの裏表を使った秘密
- オンラインセッションツールでの白紙のカードの扱い

## 理由

- 柱を確かめるのに要るものだけを入れた。コアは体験の核そのもの。戦闘は、柱2（計算は1手）と柱3（数字の成長も深く）がぶつからないかを確かめるのに要る。
- 人間は、シナリオの進み方の好みとして、ソード・ワールド2.0 のミストキャッスル（ゲームブック型で、みんなでも1人でも遊べる）を挙げた。束を読めば進める形にしておけば、当面の試遊（人間が1人で GM と PL を兼ねる、DR-0006）と、AI がルールだけを読んで遊ぶ試遊も楽になる。
- GM がいないときの白紙のカードの認め方は柱1 に関わる大きな問いなので、最初の1回からは外した。
- キャラクターメイクを出来合いにしたのは、1回通すのを先にするため。柱3 の「深く選べる」は、メイクの手順を足すときに確かめる。
- カードの裏表の秘密は、PL 1人では隠す相手が GM だけになり、効き目を試しにくい。

## 採らなかった案

- **最初から GM がいない形でも遊べるようにする** — 白紙のカードの認め方まで決める必要があり、束が膨らむ。
- **GM がいない形を、シナリオの束の形ごと後から足す** — 後で束を作り直すことになる。束の形だけなら、いま決めても重くない。

## 後で見直すとき

最初の1回を通した後（後から足すものを、どの順に入れるか）。
