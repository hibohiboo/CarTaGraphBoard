# DR-0010 コア

- 状態：採用（足跡という名前は C5 で人間が決めた）
- 日付：2026-11-01
- サイクル：[C4](../cycles/2026-11-01-C4-前のリポジトリの仕分け.md)
- 反映先：[コンセプト](../design/vision.md#コアと、そうでないところ)

## 問い

力を入れて独自に作る仕組み（コア）と、既存のゲームの定番で済ませる仕組みはどれか。

## 決めたこと

コアは次の4つ。

1. 白紙のカードを書き、GM が認め、卓に残す。
2. キャラクターはデッキで表し、成長するとデッキが育つ。
3. ふだんは手札から選んで物語に関わる。
4. 出したカードを順に並べ、回の跡（足跡）として残す。

判定のダイス、戦闘の基本の形、シナリオの束の進め方（ゲームブックのように）は、定番で済ませる。

## 理由

- ①・③は体験の核（[DR-0003](DR-0003-体験の核.md)）と柱1・柱4（[DR-0007](DR-0007-デザインの柱.md)）そのもの。
- ②は柱3 と、人間の「キャラクターをデッキで表したい」から。
- ④は人間の「出したカードの履歴がログとして見えるのが好き」「遊び終えた後に何か残るのが好き」から。体験の核の「積み上がっていくのを味わう」を、1回の中で目に見える形にする。
- 判定・戦闘・シナリオの進め方は、体験の核に直接は効かない。人間が遊んできたゲームに定番の形がたくさんあり、借りれば分かりやすい。
- 「足跡」という名前は AI が仮に付け、C5 で人間がそのままでよいと決めた（短く、日常の言葉なので）。

## 採らなかった案

- **④をコアに入れない（定番の記録用紙で済ませる）** — 積み上がりを目に見せる仕組みは既存の TRPG に多くなく、体験の核に効くので独自に作る。

## 後で見直すとき

試遊で、④の並べる手間が遊びを止めたとき（柱2）。
