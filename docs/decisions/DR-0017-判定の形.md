# DR-0017 判定の形

- 状態：採用
- 日付：2026-11-03
- サイクル：[C8](../cycles/2026-11-03-C8-判定と戦闘.md)
- 反映先：[ルール](../design/rules.md#判定)、[コンポーネント](../design/components.md)、[用語集](../design/glossary.md)

## 問い

- 判定をどんな形にするか（定番で済ませる。[DR-0010](DR-0010-コア.md)）。
- シーンのカードに、判定の成功と失敗の行き先をどう書くか（[DR-0013](DR-0013-シーンと手札のつながり.md)）。
- 対決（攻撃など）で、誰がダイスを振るか。

## 決めたこと

- 判定は「2d6＋出したカードの修正 ≥ 目標値」。目標値以上なら成功。
- シーンのカードの選択肢に、判定を付けて書ける（例：「【剣】判定9 → 成功 4／失敗 5」）。PL はそのタグを持つカードを手札から出して振る。
- 「振らない」と書いたカード（支援・回復など）は、出せば振らずに成功する。ただし、シーンのカードが判定を求めたときは振る。
- 対決では PL だけが振り、敵は固定の値を持つ。戦闘での当て方は [DR-0018](DR-0018-戦闘の形.md)。
- 目標値の目安は、易しい7・ふつう9・難しい11（仮）。シナリオを作るときの目安で、ルールでは縛らない。

## 理由

- 人間の好み：支援や回復は、カードを出すだけで成功するとよい。攻撃の対決は、ダイスを振るドキドキが好き。戦闘の外なら、支援や回復で判定させてもよい（場合による）。
- 計算は足し算1回で済む（柱2）。シーンのカードの選択肢の書き方（DR-0013）に、行き先が1つ増えるだけで、手札から選んで進むこと（柱4・コア3）がそのまま判定になる。
- 振るのを PL だけにすると、GM 1人の手間が減る（ソード・ワールド2.x の固定値の考え方）。

## 採らなかった案

- **対決で GM と PL が両方振って比べる** — ドキドキは増えるが、1回の判定が2手になる。
- **出したカードの数だけダイスを振るダイスプール** — 目を数える手間が増える。
- **判定を、選択肢とは別の「判定のシーン」にする** — シーンの書き方が2通りになる。
- **失敗の行き先を書かず、失敗したら HP などが減るだけにする** — 失敗が物語の分かれ道にならない。

## 後で見直すとき

試遊で、目標値の目安が易しすぎる・難しすぎるとき。「振らない」カードが強すぎるとき。
