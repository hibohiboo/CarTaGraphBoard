# 決定

> **3行で**
> 1. 決めたことの理由と、採らなかった案を、1決定1ファイルで残す（ADR の形。`DR-<4桁の番号>-<題>.md`）。
> 2. 結論そのものは `docs/design/` にあり、ここは「なぜ」を書く。
> 3. 覆したら新しい決定を作り、古いほうは消さずに「置き換え」と書く。

## 型

```markdown
# DR-<番号> <題>

- 状態：採用 ／ 置き換え（DR-xxxx で） ／ 取り下げ
- 日付：YYYY-MM-DD
- サイクル：C<番号>（決めたサイクルの記録へのリンク）
- 反映先：docs/design/… の節

## 問い

何を決める必要があったか。

## 決めたこと

## 理由

デザインの柱のどれに照らしたか。確かめたこと（試した・数えた）があれば添える。

## 採らなかった案

案ごとに、採らなかった理由。後で戻るときの手がかりにする。

## 後で見直すとき

どうなったら見直すか（試遊でこうなったら、など）。無ければ省く。
```
