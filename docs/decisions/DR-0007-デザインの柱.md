# DR-0007 デザインの柱

- 状態：採用（キャラクターメイクのツールを作る時期は仮）
- 日付：2026-11-01
- サイクル：[C3](../cycles/2026-11-01-C3-デザインの柱.md)
- 反映先：[コンセプト](../design/vision.md#デザインの柱)

## 問い

- 体験の核を支え、判断に迷ったときの物差しになる柱は何か。柱どうしがぶつかるときの優先順は。
- TRPG の「何でもできる」と、ボードゲームの「ルールで決まった選択肢」を、どこで折り合わせるか。

## 決めたこと

柱は4本で、番号の小さいほうを優先する。

1. 思いつきは、書けばすぐ使える。
2. セッション中の計算は道具に任せ、遊びを止めない（紙では早見表とシートの欄、オンラインセッションツールではチャットパレット）。
3. 育つ楽しさは、数字とカードの両方で味わう。キャラクターメイクは自前のツールで支える（作るのはフェーズ5、それまでは紙のシート。仮）。
4. 手札が土台、思いつきが上乗せ（これが折り合いの答え）。

## 理由

- 柱1 は体験の核（[DR-0003](DR-0003-体験の核.md)）そのもの。書くのが重いと白紙のカードが書かれず、核が起きない。
- 柱2 と柱3 は人間の答えから。「リソース管理が好き。計算はツールで支え、キャラクターの成長の楽しさを演出したい。ガープスはキャラメイクが楽しかったが、セッションは難しすぎた」。難しさを、キャラクターメイクと成長（深くてよい）と、セッション（止めない）に分けた。
- 柱2 を柱3 より上にしたのは、ガープスで困ったのが「セッションが止まる」ことだったため。
- 柱2 の道具を早見表とチャットパレットにしたのは、[DR-0001](DR-0001-ボードゲームとして先に設計する.md)（デジタルはフェーズ5まで作らない）と [DR-0005](DR-0005-紙とオンラインツールの両方で遊ぶ.md)（紙とオンラインセッションツール）の範囲に収まるため。
- キャラクターメイクを自前のツールで支えるのは人間の答え。作る時期を「フェーズ5、それまでは紙」と読んだのは、DR-0001 と食い違わないようにするための AI の置き方で、人間に確かめるまで仮。
- 柱4 は、「何でもできる」が入る口を白紙のカードの1つに絞る。ふだんはボードゲームらしく手札から選ぶ。
- 人間は、ゲームブック形式に似た体験だとも言った。番号の付いた場面を選んで進む形は、シナリオの束の形の候補として、フェーズ2の問いに残した。

## 採らなかった案

- **柱「育ったものは手で触れて見える（数値の帳簿だけの成長にしない）」** — 数字の成長を楽しみたいという人間の意図と合わない。柱3 に直した。
- **柱「束を開けば、2人ですぐ遊べる」** — 柱にせず、やらないこと（GM の事前のシナリオ作り、[DR-0008](DR-0008-やらないこと.md)）で受けた。
- **折り合い：宣言は自由、判定だけカード** — TRPG に近いが、白紙のカードを書く理由が薄れる。
- **折り合い：全部カード、白紙のカードはシナリオの終わりにだけ書く** — 遊びは止まらないが、その場で思いつく楽しさが消える。
- **セッション中も自前の計算ツールを使う** — DR-0001 と食い違う。チャットパレットで足りるかを先に試す。

## 後で見直すとき

人間がキャラクターメイクのツールを作る時期を確かめたとき。試遊で、早見表やチャットパレットでは計算が1手で済まないと分かったとき。
