# DR-0016 配るカードの行き先とプロキシの枚数

- 状態：採用
- 日付：2026-11-02
- サイクル：[C7](../cycles/2026-11-02-C7-キャラクターのデッキ.md)
- 反映先：[ルール](../design/rules.md#ビート)、[コンポーネント](../design/components.md)、[用語集](../design/glossary.md)

## 問い

- 配るカードを出した後、どこへ行くか（[DR-0014](DR-0014-足跡とプロキシ.md) の仮：捨て札へ置き、返すときに束へ返す）。
- プロキシは、1枚のカードにつき何枚要るか。
- 1枚のカードに、タグをいくつ付けるか（[DR-0011](DR-0011-タグ.md)）。

## 決めたこと

- 出した配るカードは、すぐシナリオの束へ返す（使い切り）。出さなかった配るカードは、カードに書いた「返すとき」に返す。
- プロキシは、最初の1回では、シーンのカード1枚につき1枚、配るカード1枚につき1枚、キャラクターのデッキのカード1枚につき3枚を用意する。足りなくなったら、白紙のプロキシに名前を書いて使う。
- タグの数は、ルールでは縛らない。カードを作るときの目安を「ふつうは1〜2個」とする。スキルやアイテムには、もっと付けてよい。選択肢のカード（「頷く」など）は、カードの名前を1個のタグにする（【頷く】）。

## 理由

- 配るカードの行き先が「出したら束へ」「出さなければ返すときに束へ」の2通りになり、捨て札が要らなくなる。紙で扱う置き場が1つ減る（柱2）。何度も使いたいものは、報酬としてキャラクターのデッキのカードにする筋道がある（DR-0013）。
- 同じものを何度も出しうるのは、キャラクターのデッキのカード（倒して起こせば何度でも出せる。[DR-0015](DR-0015-キャラクターのデッキとアクティブ.md)）と、同じシーンを2回通るときだけ。配るカードは使い切りなので1枚で足りる。白紙のプロキシに書くのは1語で済み、柱1 と同じ手触り。
- タグを2個付けると、1枚で2つの選択肢に使え、キャラクターのデッキのカードを出す場面が増える。3個以上はシーンを作る側が見通しにくく、人間が TCG で困った「ぱっと分からない」に近づく。一方で、スキルやアイテムには付けたくなる（人間）。ルールで縛らず、作るときの目安にする。

## 採らなかった案

- **配るカードを捨て札に置き、返すときに返す（DR-0014 の仮）** — 置き場が1つ増える。
- **カードごとに「出したら返す／手札に残る」を書く** — カードの文が増える。
- **どのカードもプロキシ2枚ずつ** — 配るカードとシーンの分が余り、キャラクターのデッキのカードの分が足りない。
- **プロキシをやめ、足跡は紙に名前を書く** — DR-0014 で採った、カードが並ぶ足跡を手放す。
- **タグは1個だけ／1〜2個をルールで決める** — スキルやアイテムを表しきれない。

## 後で見直すとき

試遊で、キャラクターのデッキのカードのプロキシ3枚が足りない・余るとき。タグの多いカードが、シーンを作るときや遊ぶときに分かりにくいとき。
