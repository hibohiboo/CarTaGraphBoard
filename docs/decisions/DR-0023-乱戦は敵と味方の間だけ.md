# DR-0023 乱戦は敵と味方の間だけ

- 状態：採用
- 日付：2026-11-24
- サイクル：[C10](../cycles/2026-11-24-C10-AIの試遊.md)
- 反映先：[ルール](../design/rules.md#攻撃と-hp)、[用語集](../design/glossary.md)、[コンポーネント](../design/components.md#シナリオの束)

## 問い

[DR-0018](DR-0018-戦闘の形.md) の「隣り合ったコマは、つながって1つの乱戦になる」をそのまま読むと、味方どうし（リオとミナ）が隣り合うだけで乱戦になる。リオが離れるだけで「乱戦から抜ける」2カウントが要り、ミナの「乱戦に入らないように近づく」はリオの隣に行けない意味になった（[T1](../playtests/2026-11-24-T1-冒険者試験.md) 詰まり E）。

## 決めたこと

- 乱戦は、敵のコマと、PC か仲間のコマが隣り合ったときにできる。同じコマを通してつながった乱戦は、1つの乱戦とする。味方どうしが隣り合うだけでは、乱戦にならない。
- 範囲を攻撃するカードで「対象：乱戦」（同じ乱戦の相手全員）と書けるのは、射程の無いカードだけ。射程のある範囲の攻撃は、マスで範囲を書く。

## 理由

- 人間が推奨を選んだ。T1 はこの読み方で通し、詰まらなかった。
- 範囲の書き方は人間の指摘：「対象：乱戦」を近接に限らないと、離れた乱戦のどこまでが範囲か、処理に困る。遠くへの範囲攻撃はマスで表す。
- 隣り合いの判定は「敵の隣か」だけを見ればよく、紙で迷わない（柱2）。

## 採らなかった案

- **今の文のまま、味方どうしでも乱戦** — 仲間が PC から離れにくくなり、仲間の「乱戦に入らないように近づく」が PC の隣に行けない意味になる。

## 後で見直すとき

範囲の攻撃のカードを作り、マスで書いた範囲が紙で数えにくいとき。
