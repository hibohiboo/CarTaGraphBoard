# DR-0011 タグ

- 状態：採用（1枚に付けるタグの数は DR-0016 で決めた）
- 日付：2026-11-01
- サイクル：[C4](../cycles/2026-11-01-C4-前のリポジトリの仕分け.md)
- 反映先：[用語集](../design/glossary.md#タグ)

## 問い

カードとキャラクターにタグを付けたい。カードとタグの両方を持つと煩雑になるのを、どう避けるか。

## 決めたこと

- タグは、カードに書く1語のキーワードにする。1枚のカードに複数付けてよい。
- キャラクターのタグは、キャラクターのデッキにあるカードのタグの集まりとして読む。キャラクター専用のタグ欄は作らない。

## 理由

- 人間の悩み「カードとタグの両方は煩雑になるか」に対して、タグの置き場所をカードだけにすれば、増えるのは「カードに1語書く」だけになる。
- キャラクター＝デッキ（[DR-0010](DR-0010-コア.md) の②）なので、デッキのカードのタグを読めば、キャラクターのタグが分かる。
- 複数付けてよいのは、人間の答えから。人間はカードワースのキーコードの仕様がよいと思っている。キーコードと同じく、シナリオが「このタグを持つカードがあるか」で分岐する使い方の手がかりになる。

## 採らなかった案

- **キャラクターシートにもタグ欄を作る（称号など）** — 置き場所が2つになる。称号は [DR-0009](DR-0009-前のリポジトリの仕分け.md) の #14 と一緒にフェーズ2で考える。
- **タグを使わない** — 人間が付けたい。

## 後で見直すとき

フェーズ2で、1枚に付けるタグの数と、シナリオがタグをどう読むかを決めるとき。
