# DR-0006 遊ぶ場面

- 状態：採用
- 日付：2026-11-01
- サイクル：[C2](../cycles/2026-11-01-C2-遊ぶ場面.md)
- 反映先：[コンセプト](../design/vision.md#遊ぶ場面)、同「進化の表し方」「やらないこと」

## 問い

- GM を置くか。置くなら、GM は遊ぶ人の1人か、ルールやカードが GM の役をするか。
- 何人で、1回どのくらいの時間で遊ぶか。続けて遊ぶ（キャンペーン）前提か。
- 誰が、どんな気分で遊ぶか。

## 決めたこと

- GM 1人と PL 1人の2人で遊ぶ。これを設計の前提にし、ルールとバランスをこの2人で作る。PL が2人以上で遊ぶことは、いまはやらない。
- GM は人が務める。シナリオのカードの束を読みながら進め、場面を描写し、判定を裁き、白紙のカードを認める。事前の準備はほとんど要らない。
- これで、[DR-0004](DR-0004-進化の表し方.md) の「白紙のカードを誰が認めるか」の仮を外し、GM が認めるとした。
- 1回はシナリオ1本で60〜90分。キャンペーンが前提で、キャラクターのデッキと卓の箱を持ち越す。1回だけでも終わりまで遊べる。
- 気分は「気軽に座って、思いつきを出すのが楽しい」。ルールを読み込まなくても始められる。

## 理由

- 人間の答え：「将来は複数人で遊ぶ夢はあるが、遊ぶのは完成を目指すためなので、GM（わたし）と PL 1人の2名にしたい」。確かめる人数の組み合わせが1つで済み、完成までが最も速い。
- GM を人にすると、白紙のカードを認める人が1人に決まる。卓の合意を取る手順が要らない。
- GM がシナリオの束を読んで進める形にしたのは、シナリオの層（DR-0004）を「束を開けば遊べる」ものにし、ボードゲームとして設計しきる部分を厚くするため。
- キャンペーンにしたのは、体験の核（[DR-0003](DR-0003-体験の核.md)）の「積み上がっていく」が、持ち越しなしでは味わえないため。60〜90分は、試遊を何度も回せる長さ。
- 気分を「気軽に」にしたのは、白紙のカードを書く気軽さが体験の核そのものだから。

## 確かめたこと

- 当面の試遊は、人間が1人で GM と PL を兼ねて遊ぶ（人間の答え）。PL を別の人が務める試遊はまだ無い（未確認）。兼ねると、白紙のカードを認めるのが自分になるため、認める判断の重さは確かめられない。
- 60〜90分にシナリオ1本が収まるかは、ルールが無いので数えていない（未確認）。フェーズ2で1回通すときに測る。

## 採らなかった案

- **設計は PL 1〜3人、試遊だけ2人** — 後で広げやすいが、試遊していない人数のバランスを抱える。完成を先にするため採らなかった。
- **GM がシナリオを自分で作り、ルールは道具だけ** — 従来の TRPG に近く自由だが、ボードゲームとして設計しきる部分が薄くなる。
- **1回2〜3時間** — TRPG に近い長さだが、試遊の回数が減る。
- **1回30分を何度も** — 1本のシナリオで物語の山を作りにくい。
