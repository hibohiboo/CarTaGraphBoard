# DR-0002 新しいリポジトリで始める

- 状態：採用
- 日付：2026-11-01
- サイクル：[C0](../cycles/2026-11-01-C0-下準備.md)
- 反映先：このリポジトリ全体、[前のリポジトリ](../sources.md)

## 問い

設計から始め直すのを、前のリポジトリ（CarTaGraphAdventure）の中で行うか、新しいリポジトリで行うか。

## 決めたこと

新しいリポジトリ（CarTaGraphBoard）で始める。前のリポジトリは参考資料として残し、要るものだけを決定として取り込む。

## 理由

- 前のリポジトリには、実装を前提にした進め方・検査・文書（約1000行の進め方の文書、十数種類の検査）がある。中で始め直すと、それらを片付ける作業と、残すかどうかの判断が先に要る。
- 白紙から始めると、持ち込むものを1つずつ選ぶことになり、持ち込んだ理由が残る（[体制の進化ログ](../process/evolution.md)）。

## 採らなかった案

- **CarTaGraphAdventure の中に設計用のディレクトリを作る** — 既存の検査・フック・文書の決まりが設計の作業にもかかり、軽くできない。

## 後で見直すとき

フェーズ5で実装を始めるとき、実装をこのリポジトリに足すか、別のリポジトリにするかを改めて決める。
