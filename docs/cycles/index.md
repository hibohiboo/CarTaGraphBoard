# 設計サイクルの記録

> **3行で**
> 1. [設計サイクル](../process/cycle.md)ごとに、1ファイルで作業の記録を残す（`<日付>-C<番号>-<題>.md`、番号は続き番号）。
> 2. 記録は後から直さない。決めた結果は `docs/design/` と `docs/decisions/` にあり、ここはそこへ至った跡。
> 3. 再開するときは、いちばん新しい記録の「ふりかえり」の「次に試すこと」を見る。

## 型

```markdown
# C<番号> <題>

- 日付：YYYY-MM-DD
- フェーズ：<番号>
- 目指す終える条件：docs/index.md のどの条件か
- 状態：進行中 ／ 終わり（次のサイクルに残したもの：…）

## 問い

今回決める問いの束（docs/questions.md から）。

## 詰めたこと

問いごとに、出した案・柱に照らした良し悪し・推奨・人間の答え。

## 確かめたこと

頭の中で通した・数えた・試したこと。確かめていないことは「未確認」と書く。

## 決めたこと

- 決定 DR-xxxx → 反映した design/ の節
- 仮に置いたもの（「（仮）」）と、残した問い

## ふりかえり

- **進んだか** — どの終える条件に、どれだけ近づいたか
- **邪魔だったもの** —
- **次に試すこと** —
- 進め方の気づき → evolution.md の候補に足したもの
```
