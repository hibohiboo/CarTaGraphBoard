# 設計サイクルの記録

設計サイクル（[設計の進め方](../process/index.md#設計サイクル)）ごとに、1ファイルで記録を残す。ファイル名は `<日付>-C<番号>-<題>.md`。番号は続き番号。

記録は、後から直さない（その時点で何を考えたかを残すため）。決めた結果は `docs/design/` と `docs/decisions/` にあり、記録はそこへ至った作業の跡である。

## 一覧

| 番号 | 題 | フェーズ | 近づいた終える条件 |
|---|---|---|---|
| [C0](2026-11-01-C0-下準備.md) | 下準備 | 0 | 進め方・前のリポジトリのふりかえり |
| [C1](2026-11-01-C1-体験の核と進化.md) | 体験の核と進化 | 1 | 体験の核・進化の表し方 |

## 型

```markdown
# C<番号> <題>

- 日付：YYYY-MM-DD
- フェーズ：<番号>
- 目指す終える条件：docs/index.md のどの条件か
- 状態：進行中 ／ 終わり（次のサイクルに残したもの：…）

## 問い

今回決める問いの束（docs/questions.md から）。

## 詰めたこと

問いごとに、出した案・柱に照らした良し悪し・推奨・人間の答え。

## 確かめたこと

頭の中で通した・数えた・試したこと。確かめていないことは「未確認」と書く。

## 決めたこと

- 決定 DR-xxxx → 反映した design/ の節
- 仮に置いたもの（「（仮）」）と、残した問い

## ふりかえり

- **進んだか** — どの終える条件に、どれだけ近づいたか
- **邪魔だったもの** —
- **次に試すこと** —
- 進め方の気づき → evolution.md の候補に足したもの
```
