# 試遊

ルールで実際に遊んだ記録を、1回1ファイルで置く。ファイル名は `<日付>-T<番号>-<題>.md`。

試遊には2種類ある。

- **AI の試遊** — AI が [ルール](../design/rules.md) と [コンポーネント](../design/components.md) だけを読み、書いていないことを補わずに1回通す。ルールが書いていないこと・二通りに読めることで止まったら、そこを問いにする。ルールの書き漏れを見つけるのが目的。
- **人間の試遊** — 人間が紙（か紙に近いもの）で遊ぶ。楽しいか・柱を満たすかを確かめるのが目的。

## 型

```markdown
# T<番号> <題>

- 日付：YYYY-MM-DD
- 種類：AI ／ 人間（遊んだ人数）
- ルールの版：遊んだときのコミット（`git log -1 --format=%h`）
- 確かめたいこと：どの柱・どの仮のルールを確かめるか

## 遊んだ流れ

起きたことを順に。詰まったところには「詰まり」と書く。

## 分かったこと

- 柱ごとに：満たしたか、なぜそう言えるか
- 詰まったところ・二通りに読めたところ → 問い（`docs/questions.md` に足した）

## 次に試すこと
```
